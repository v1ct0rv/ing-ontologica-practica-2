06Transformación de Consultas

HyDE + Query Decomposition + Router inteligente
DIRECT
Pregunta directa
Pregunta clara y específica. Se envía directamente al retriever.

"¿Qué establece el artículo 9 de la Ley 1116?"
HyDE
Documento hipotético
Pregunta vaga o ambigua. Se genera un documento hipotético para mejorar el embedding.

"¿Qué pasa cuando no se paga?"
DECOMPOSE
Descomposición
Pregunta compleja multi-hop. Se divide en 2-4 sub-preguntas atómicas.

"Requisitos de reorganización y diferencias con liquidación"

07Agente ReAct + Reflecting

StateGraph de LangGraph con 6 nodos y edges condicionales
NodoFunciónEntradaSalida
query_transform Clasifica y transforma la consulta question route, transformed_queries
retrieve Vector Store MMR + Knowledge Graph SPARQL transformed_queries context_chunks, kg_results
generate Sintetiza respuesta con LLM context + question answer
reflect Evalúa fidelidad, completitud, precisión answer + context critique, approved
web_fallback Búsqueda DuckDuckGo (fallback) question web context

El agente usa 7 herramientas: vector_search, query_kg_procedures, query_kg_norms, query_kg_creditors, query_kg_entity, sparql_query, web_search

11Trazabilidad con LangSmith

Registro automático de cada nodo de LangGraph
●
Caso 1: Exitoso
Trace lineal: 5 nodos ejecutados en secuencia.
Reflect aprueba en primer intento.
●
Caso 2: Reintento
Trace con loop: reflect rechaza, vuelve a retrieve.
Se observa la crítica guiando la mejora.
●
Caso 3: Web Fallback
Trace extendido: 3 rechazos, web_fallback activado.
Contexto web complementa el corpus.

Cada trace registra: inputs/outputs de cada nodo, queries transformadas, documentos recuperados, prompts del LLM, scores de reflexión y tokens consumidos.

13Conclusiones

Resumen de logros del sistema Knowledge Graph RAG
01
Vector Store + KG es más poderoso que cada uno solo
La respuesta final (4.4/5) supera ampliamente las métricas de retrieval puro (0.3), demostrando la sinergia.
02
ReAct + Reflecting mejora la calidad
El ciclo de reflexión corrige respuestas incompletas y el fallback web complementa el corpus.
03
HyDE y Decomposition amplían la capacidad
Preguntas ambiguas y complejas se manejan automáticamente con las estrategias de transformación.
04
Ontología OWL aporta estructura formal
16 clases, 5 inferencias documentadas y consultas SPARQL enriquecen el contexto del agente.
